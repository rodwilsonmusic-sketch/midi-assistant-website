System requirements

Mac appmacOS 13 or later. MainStage for Host FX Mode (the AUv3 plugin). Works with any MIDI-capable software for routing and the Mixer.
iPad RemoteAn iPad on the same local network as the Mac (Wi-Fi, or wired/ad-hoc for the most stable connection).
ControllersAny class-compliant MIDI controller. Launch Control XL and Lemur layouts are supported out of the box.

Frequently asked questions

My iPad isn't syncing with the Mac
  • Confirm both devices are on the same local Wi-Fi network, or use a stable wired/ad-hoc connection.
  • Check that macOS's local-network permission prompt for MIDI Assistant wasn't dismissed as Deny (System Settings → Privacy & Security → Local Network).
  • Make sure no firewall is blocking local UDP traffic between the two devices.
Host FX Mode in MainStage isn't responding
  • Confirm the MIDI Assistant AUv3 plugin is loaded on the channel strip you want to control.
  • In the Performance Hub, check the Processing Mode is set to Host FX rather than Hub Processing.
  • If MainStage was open before MIDI Assistant was installed, restart MainStage so it rescans plugins.
My hardware fader jumped when I changed Scenes

Turn on Soft Takeover for that port in the MIDI Routing window. Pickup waits for the fader to cross the current value; Proportional scales your movement so it catches up smoothly. Pick whichever feels right for the control.

A fader is noisy or twitchy when I'm not touching it

That's electrical jitter from the analog control. The Jitter Lock Filter handles it automatically; if it still seems too sensitive or too sluggish, check the port's routing settings.

A port stopped passing notes after I changed a mapping

Check the port's Namespace and active-state settings in the MIDI Routing window before assuming a fault. A port whose Namespace isn't active for the current Scene is muted by design — that's what lets you switch rigs per Scene.

Where are my Concerts stored?

In ~/Documents/MidiAssistantData by default. You can choose a different folder in Settings; MIDI Assistant remembers it between launches.

Does MIDI Assistant collect any data?

No. It runs entirely on your device and local network, collects no personal information, and uses no analytics or advertising frameworks. See the Privacy Policy.

Does it work without MainStage?

Yes. Host FX Mode is MainStage-specific, but the Mixer, Concert Editor, and routing engine speak standard MIDI and work alongside Logic Pro, Ableton Live, or any other MIDI-capable software.
